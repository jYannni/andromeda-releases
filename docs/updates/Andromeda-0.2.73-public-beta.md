## Added

- Opt in to public beta updates in Settings → Updates on public builds.
- What’s New groups changes into the releases published for your build’s channel.
- Public Beta has a blue galaxy icon with PUBLIC and BETA badges. Private Beta has a violet galaxy icon with a tilted grid and PRIVATE and BETA badges.
