# Andromeda 0.2.70

Andromeda shows what uses space on your Mac and lets you review cleanup and file organization.

Requires an Apple silicon Mac with macOS 26 or later.

## Changed

- DiskPlain is now Andromeda, with a blue-to-purple galaxy icon.
- The in-app logo displays in color when its window is active and in grayscale when it is inactive.
- Andromeda keeps the settings, history, and archives from earlier versions.
- This is the first public release. Install it once from the public download to switch from an earlier private beta to the new update feed.

## Install

Open the DMG and drag Andromeda to Applications. If you used the private beta, quit DiskPlain and replace that app with Andromeda. You can check for future updates in Settings → Updates.
